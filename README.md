# Lewis Cheng - Portfolio

Static site for GitHub Pages. No build step.

## Publish
1. Create a **public** repo named `lewischeng2507.github.io`.
2. Upload everything in this folder to the repo root (keep `index.html` at the top level).
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Visit https://lewischeng2507.github.io in a minute or two.

## Add photos
Drop files into `assets/images/` using the names shown in each placeholder
(`glenair-1.jpg`, `nasa-1.jpg`, `fsae-1.jpg`, `first-1.jpg`, `solar-boat-1.jpg`).
Add `hero.jpg` for the top banner (a wide sunset photo works well).
To use different names, edit the `src` and `data-file` in `index.html`.
